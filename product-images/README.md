# Product Images Directory

This directory stores high-resolution and optimized web photos for Miss Roses Exquisite:

## Subfolders / Categories:
- `dresses/` — Evening wear, casual dresses, traditional wear, gowns.
- `bangles/` — Gold-plated, beaded, brass, and luxury bangles.
- `slippers/` — Leather slippers, slides, embellished sandals.

## Guidelines:
1. Supported formats: `.webp`, `.jpg`, `.png`.
2. Recommended resolution: Minimum 800x800px (1:1 square) or 800x1200px (portrait) for clean product displays.
3. Optimize images before uploading to ensure quick page loads on mobile devices.
